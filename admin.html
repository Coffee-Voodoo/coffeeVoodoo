How to Update the Menu

Because this website is hosted statically on GitHub Pages, menu updates must be done directly through GitHub.

  1. Go to your GitHub Repository.
  2. Navigate into the menuFiles folder.
  3. Click Add file -> Upload files.
  4. Upload your new PDF file and make sure it is named exactly menu.pdf (this will overwrite the old one).
  5. Click Commit changes. Your live website will update within a minute or two!
